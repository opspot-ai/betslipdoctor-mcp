# BetSlip Doctor

Use the `bsd` MCP server (https://api.betslipdoctor.ai/api/mcp) for the signed-in
user's own BetSlip Doctor account. Follow `skills/bsd-workflow/SKILL.md`.

- Read saved Grades, Doctor conversations, History and Tail with the read tools;
  reading never starts paid work.
- New Grades and Doctor replies: quote first, show the allowance cost, start only
  after the user accepts.
- Tail posts: show the exact preview, publish only on explicit confirmation.
- BSD never places bets, moves money or asks for sportsbook logins. A sportsbook
  link opens only when the user taps it.
- A Grade is research. Historical support is not a win probability.
